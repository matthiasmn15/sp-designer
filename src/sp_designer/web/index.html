    Spark Plug Designer – Materials

    • Compare: pick up to four materials (A–D) and compare all properties side by side.
    • Ranking: weight the selection criteria; materials are scored within the candidate set.
    • Charts: bar chart per property and a selection map (e.g. erosion indicator vs. cost per volume).
    • Database: add own materials and alloys, override reference values.
    • Prices: automatic indicative prices with date stamp, or manual entries.
    • Pure-element data is imported automatically from the bundled mendeleev database. Alloy properties without datasheet values are estimated from the composition.
